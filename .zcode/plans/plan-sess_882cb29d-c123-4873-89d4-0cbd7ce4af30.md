# Kế hoạch: Workflow nâng cấp dashboard — TradingView Widgets + dự báo phiên mai + panel DNSE (read-only)

## Yêu cầu (đã chốt với user)
- TradingView Widgets (miễn phí, nhúng script/iframe) làm hình ảnh chính: biểu đồ, bảng giá, kỹ thuật + **1 dòng dự báo phiên mai** trên dashboard
- Panel **DNSE mức ĐỌC** (LightSpeed REST): **giữ, tắt mặc định** — MCP DNSE vừa kết nối KHÔNG có tool xem tài khoản cá nhân nên panel vẫn qua REST với JWT; MCP dùng cho agent trong chat (không thay đổi thiết kế)

## Nền tảng đã khảo sát (file:line thực tế)
- `app/dashboard.py` (1050 dòng): nav `st.radio` + `session_state["nav"]`, 4 tab; chưa có st.components/iframe nào; tab 3 chart plotly inline (603–661); `forecast_summary(conn, ticker)` gọi ở 672 (sau chart) — kéo lên dùng chung
- Bẫy đã xác minh: app dùng giá **nghìn đồng**, TradingView dùng VND thô → quy đổi ×1000; `predicted_price`/`probability_up` có thể `None`; chưa train → `has_run=False`
- Dashboard tương thích `streamlit.testing.v1.AppTest` → smoke test headless làm gate mạnh
- **DNSE MCP chính thức đã kết nối và probe OK** (`mcp.dnse.com.vn/mcp`, ~40 tools; đơn vị giá cũng nghìn đ) — sau khi run xong tôi có thể dùng MCP đối chiếu chéo giá TCB với pipeline. Panel tài khoản vẫn qua LightSpeed REST (services.entrade.com.vn, JWT từ Entrade X), chỉ endpoint đọc

## Thiết kế sản phẩm
1. **Banner "DỰ BÁO PHIÊN MAI" toàn cục** dưới header (mọi tab): giá (nghìn đ + ≈ VND), hướng, P(tăng), đồng thuận n/N model, nguồn run; xử lý chưa train/None
2. **Tab 3**: thay chart plotly giá bằng **Advanced Chart** (`HOSE:{ticker}`, RSI+Volume, height 620) + **Technical Analysis gauge**; plotly cũ là fallback khi `app.tradingview.enabled=false`; SHAP giữ nguyên
3. **Tab 1**: **Market Overview** (VNINDEX + watchlist) · **Toàn trang**: Ticker Tape mảnh
4. **Tab "Danh mục"**: section "Tài khoản DNSE" — bảng vị thế (mã, KL, giá vốn) + cột "Dự báo ngày mai" từ `tomorrow_consensus()`; ẩn hoàn toàn khi disabled/không token; lỗi token → warning, không crash
5. `src/forecast.py`: hàm thuần `tomorrow_consensus()` + test · `src/dnse_client.py`: client read-only (accounts/positions/orders), mock-test offline, **KHÔNG có endpoint đặt lệnh**
6. config.yaml: `app.tradingview: {enabled: true, exchange: "HOSE"}` · `app.dnse: {enabled: false, jwt_token: "", account_no: ""}`
7. Giữ nguyên: 4 tab, tiếng Việt, pipeline chỉ chạy khi nhấn nút, pattern AppTest

## Topology workflow (4 subagent, 2 gate)
1. **Kỹ sư dashboard** (1 ask): dashboard + forecast helper + dnse_client + 3 file test + config
2. **Gate**: `pytest` toàn bộ + `py_compile` (Anaconda `C:/ProgramData/anaconda3/python.exe`) — vòng fix trần 4
3. **Kiểm tra viên độc lập** (chỉ đọc): nhúng widget đúng · banner nguồn DB + None + ×1000 + has_run · tương thích AppTest · DNSE read-only tuyệt đối, tắt mặc định, không rò token · 4 tab nguyên vẹn
4. **Xác nhận viên** mỗi finding (tái hiện bằng đọc code) + **Người sửa lỗi** sửa verified (trừ low) → gate lại
- Báo cáo tổng (artifact markdown primary) + WorkflowReport

## Chưa phủ
Widget render thật trên trình duyệt (AppTest chỉ stub) · panel DNSE chưa test với token thật · widget cần internet phía trình duyệt

const fixer = agent("Người sửa lỗi", ENGINEER);

async function gateWithFixes(maxRounds: number): Promise<boolean> {
  for (let round = 1; round <= maxRounds; round++) {
    const t = await world.run(PY, ["-m", "pytest", "tests", "-q"], { timeoutMs: 600_000 });
    if (t.exitCode === 0) return true;
    await fixer.ask(`pytest đang đỏ (vòng ${round}). Lỗi:\n${t.stderr.slice(0, 8000)}\nSửa cho xanh. Không xóa hoặc làm yếu test.`);
  }
  return false;
}
